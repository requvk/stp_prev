# Участие в разработке

Проект экспериментальный. Небольшие исправления и воспроизводимые сообщения
об ошибках полезнее широких переписываний без замеров.

## Окружение

Windows x64, Python 3.14 x64 с pip, PowerShell 5.1 или 7 и интернет при первой
сборке. Из корня исходников:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

Скрипт собирает C-код с предупреждениями как ошибками и выполняет тесты.
Зависимости сохраняются в `.tools/`, результаты — в `artifacts/`.
Они не входят в коммит. `-SkipTests` не подходит для проверки pull request.

Основные компоненты и команды сборки описаны в [README](README.md).
Тесты генерируют геометрию самостоятельно и вызывают DLL без установки рабочего
обработчика в реестр. Ручная проверка в Проводнике — отдельный этап;
успех прямого COM-теста не доказывает работу изолированной Shell-активации.

## Изменения

- Опишите наблюдаемую проблему и результат исправления.
- Для исправления сложного поведения добавьте проверку, воспроизводящую проблему.
- Для оптимизации укажите модель/её размер, размер изображения, число запросов,
  холодный или прогретый процесс, последовательный или параллельный режим.
- Сохраняйте ограничения ресурсов, системную COM-изоляцию и восстановление
  чужих регистраций. Их изменение требует явного обоснования.
- Если меняются зависимости, обновите [THIRD_PARTY.md](THIRD_PARTY.md),
  уведомления о лицензиях и проверьте условия распространения нового комплекта.

Не добавляйте чужие CAD-модели без права на публикацию. Для issue и тестов
предпочтительна минимальная синтетическая модель. Удаляйте из журналов
имена пользователей, внутренние пути и другие персональные данные.

Отправляя собственный код, вы предлагаете распространять его по [MIT](LICENSE).
Заимствованные фрагменты должны иметь совместимую лицензию, ссылку на источник
и сохранённые обязательные уведомления.
